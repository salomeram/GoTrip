Como usar o GoTrip

Escolha uma pergunta e clique para abrir o passo a passo.

Home

Como pesquisar um destino?
  1. Acesse a página Início.
  2. Localize o campo Buscar destino.
  3. Digite o nome de uma cidade ou país.
  4. Clique em Buscar.
  5. Confira os destinos encontrados na seção Destinos em alta.
Como acessar os recursos do GoTrip?
  1. Acesse a página Início.
  2. Localize a seção Acesso rápido.
  3. Escolha entre Agenda, Mapa ou Perfil.
  4. Clique na opção desejada para acessar a página.

Cadastro

Como criar uma conta no GoTrip?
  1. Acesse a página Início.
  2. Clique em Criar conta.
  3. Preencha o campo Nome completo.
  4. Digite seu E-mail.
  5. Informe seu CPF.
  6. Preencha o campo Telefone.
  7. Clique em Criar conta.
  8. Se o cadastro for realizado com sucesso, você será direcionado para o Perfil.
O que fazer se não conseguir criar minha conta?
  1. Confira se todos os campos foram preenchidos.
  2. Verifique se o e-mail está correto.
  3. Confira se o CPF está no formato solicitado.
  4. Clique novamente em Criar conta.

Login

Como entrar na minha conta?
  1. Acesse a página Início.
  2. Clique em Entrar.
  3. Digite seu Endereço de e-mail.
  4. Preencha o campo Senha.
  5. Clique em Entrar.
  6. Se o e-mail estiver cadastrado neste navegador, você será direcionado para o Perfil.
O que fazer se não conseguir entrar?
  1. Confira se o endereço de e-mail está correto.
  2. Verifique se você já criou uma conta neste navegador.
  3. Se ainda não tiver uma conta, clique em Criar conta.
  4. Preencha os dados solicitados para realizar o cadastro.

Destinos

Como ver os destinos disponíveis?
  1. No menu do topo, clique em Destinos.
  2. Role a página até a seção Destinos em alta.
  3. Veja as opções de lugares para conhecer e visitar.
Como visualizar informações de um destino?
  1. Acesse a seção Destinos em alta.
  2. Escolha um destino disponível.
  3. Clique no nome do lugar desejado.
  4. Confira as informações sobre o destino.

Perfil

Como ver as informações do meu perfil?
  1. Entre na sua conta clicando em Entrar.
  2. Depois do login, você será direcionado para o Perfil.
  3. Se estiver em outra página, vá até a seção Acesso rápido da página Início e clique em Perfil.
  4. Confira seu nome, e-mail, CPF e telefone.
